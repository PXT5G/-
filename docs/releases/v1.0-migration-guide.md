# GULFOS v1.0 Migration Guide

## From Development Branches

If you were running a `cursor/gulfos-*` development branch:

1. **Pull latest** from your target release branch
2. **Run full build:** `npm run build`
3. **Clear browser storage** (optional, for clean Zustand state)
4. **Re-authenticate** and call system ready

No database migrations are required — all Phase 5.x models use forward-compatible schemas.

## New Permissions (Phase 5.3–5.5)

System boot now grants permissions to:
- `com.gulfos.assistant`, `com.gulfos.automation`, `com.gulfos.shortcuts`
- `com.gulfos.focus`, `com.gulfos.intelligence`
- `com.gulfos.personalization`, `com.gulfos.security`, `com.gulfos.privacy`
- `com.gulfos.cloud`, `com.gulfos.find-my`, `com.gulfos.developer`
- `com.gulfos.analytics`, `com.gulfos.enterprise`

If apps show permission errors, trigger `POST /api/system/ready`.

## New Applications

Install from home screen or GULF Store. Runtime apps are pre-registered:
- Intelligence Hub, Personalization, Performance
- Security, Privacy, GULF Cloud, Find My
- Developer, Analytics, Diagnostics, Enterprise, Updates

## Search Categories

Global search now includes `mail`, `assistant`, and `shortcuts` in addition to existing categories.

## Settings Changes

- **Reduce Motion** now affects Lock Screen charging animation and Home Screen transitions
- Premium profile `reduceMotionOverride` respected system-wide

| Prefix | Phase |
|--------|-------|
| `/api/assistant`, `/api/automation`, `/api/shortcuts`, `/api/focus`, `/api/intelligence` | 5.3 |
| `/api/personalization` | 5.4 |
| `/api/security`, `/api/privacy`, `/api/cloud`, `/api/find-my`, `/api/updates`, `/api/developer`, `/api/analytics`, `/api/diagnostics`, `/api/enterprise` | 5.5 |

## Rollback

To rollback from v1.0:
1. Deploy previous API/web artifacts
2. MongoDB data remains compatible — no downgrade migration needed
3. New collections (ThemeProfile, SecurityProfile, etc.) are ignored by older code

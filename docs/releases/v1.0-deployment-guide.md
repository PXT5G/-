# GULFOS v1.0 Deployment Guide

## Prerequisites

| Requirement | Version |
|-------------|---------|
| Node.js | 20.x LTS |
| MongoDB | 6.0+ |
| npm | 10+ |

## Environment Variables

```bash
# API (.env in apps/api or root)
MONGODB_URI=mongodb://localhost:27017/gulfos
JWT_SECRET=<strong-random-secret>
JWT_REFRESH_SECRET=<strong-random-secret>
CORS_ORIGIN=https://your-domain.com
PORT=4000
NODE_ENV=production

# Web
NEXT_PUBLIC_API_URL=https://api.your-domain.com
```

## Build

```bash
npm install
npm run build
```

Build order: `@gulfos/shared` → `@gulfos/api` → `@gulfos/web`

## Start API

```bash
cd apps/api
npm start
```

On boot the API will:
1. Connect to MongoDB
2. Ensure production indexes
3. Seed store catalog if empty
4. Seed world map if needed
5. Start background service manager

## Start Web

```bash
cd apps/web
npm start
```

## Health Check

```bash
curl https://api.your-domain.com/health
```

Expected: `{ "success": true, "data": { "status": "healthy" } }`

## Post-Deploy Initialization

Each user session should call `POST /api/system/ready` (authenticated) to initialize:
- Phone OS, premium experience, communication
- Bank, Identity, Assistant, Automation, Intelligence
- Personalization, Security profiles
- Permission grants for core apps

## MongoDB Backup

```bash
mongodump --uri="$MONGODB_URI" --out=./backup-$(date +%Y%m%d)
```

## Rollback

1. Restore previous deployment artifact
2. Restore MongoDB from backup if schema changed
3. Verify `/health` and login flow

## Monitoring

- API logs: `[GULFOS API]` prefix
- Background tasks: `GET /api/developer/dashboard` (authenticated)
- Diagnostics: `GET /api/diagnostics/center`
